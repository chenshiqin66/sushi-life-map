# 苏轼人生轨迹交互地图 — 设计文档

## 1. 项目概述

**项目名称：** 苏轼人生轨迹交互地图（Sushi Life Map）
**项目类型：** 独立 Web 应用（React + Vite）
**核心功能：** 在交互式地图上标注苏轼一生关键地点，展示其贬谪轨迹，支持时间轴浏览，并计算总旅程里程。
**目标用户：** 文学爱好者、历史爱好者、学生

---

## 2. 技术栈

| 层级 | 技术选型 |

## 4. 功能规格

### 4.1 交互式地图
- OpenStreetMap 底图，使用 Leaflet.js 渲染
- 地图中心默认在中国东部（武汉附近），缩放级别 5
- 各事件点以不同颜色标记：
  - `birth` — 绿色
  - `official` — 蓝色
  - `exile` — 红色
  - `death` — 灰色
  - `other` — 黄色
- 鼠标悬停显示地点名称
- 点击标记弹出详情卡片

### 4.2 时间轴面板
- 位于界面左侧，垂直排列
- 显示年份 + 地点名
- 点击年份项：地图飞往该点，弹出详情卡
- 当前"活跃"年份高亮显示
- 支持拖动滑块快速跳转年份

### 4.3 地点详情卡
- 点击地图标记或时间轴项目后，在右侧/底部展开
- 显示：年份、地点、事件描述、代表诗词
- 关闭按钮

### 4.4 旅程里程计算
- 使用 Haversine 公式计算相邻节点间的球面距离
- 底栏显示：「苏轼一生总旅程约 XXXX 公里」
- 计算逻辑：按时间顺序，累加相邻事件点间的 Haversine 距离

### 4.5 轨迹动画（可选增强）
- 提供"播放"按钮
- 沿时间顺序逐个点亮标记点
- 每次点亮之间间隔 800ms

## 6. Haversine 公式

```js
function haversine(lat1, lng1, lat2, lng2) {
  const R = 6371; // 地球半径（公里）
  const dLat = (lat2 - lat1) * Math.PI / 180;
  const dLng = (lng2 - lng1) * Math.PI / 180;
  const a = Math.sin(dLat/2)**2 +
            Math.cos(lat1*Math.PI/180) * Math.cos(lat2*Math.PI/180) *
            Math.sin(dLng/2)**2;
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
}
```
